### Hi there, I'm Ryan Baumann ([@atlas-v](https://github.com)) 👋

**Robotics & Controls Engineer** specializing in the intersection of software, hardware, and machine vision systems. Currently building custom automated machines and perception pipelines for Fortune 500 manufacturing while developing autonomous robotics and self-hosted infrastructure on the side.

- 🔭 **Currently building:** **Sentinel**, an autonomous UGV powered by a distributed processing topology pairing a **Raspberry Pi 5** system brain with a **Zephyr RTOS** microcontroller over custom serial links.
- ⚙️ **Enterprise Focus:** Architecting 3D spatial registration systems, high-resolution perception pipelines (64MP/LiDAR), PLC architectures, and full-stack deployment utilities.
- 🖥️ **Self-Hosted & Telemetry:** Running **[Pulse Robotics](https://www.pulserobotics.com/)**, a self-hosted multi-server Linux/PostgreSQL array running automated Python pipelines that ingest and process daily telemetry across 11,000+ market tickers.
- 🌐 **Portfolio & Projects:** [ryanbaumann.me](https://www.ryanbaumann.me/) | [pulserobotics.com](https://www.pulserobotics.com/)
- 🤝 **Open to collaborating on:** Embedded C++/Zephyr firmware, LiDAR & 3D point cloud processing, kinematic motor control, and industrial IoT tooling.
